Add Your OpenAI API Key to Vercel

Activate AI features on your live PQE AI Assistant deployment

Your app is already live at https://pqe-ai-assistant.vercel.app
Everything works except AI features — they need your OpenAI API key added as a server-side environment variable in Vercel. This takes about 2 minutes.

Don't have an OpenAI API key yet?

  1. Go to https://platform.openai.com/api-keys
  2. Sign in or create a free account
  3. Click Create new secret key
  4. Copy the key — it starts with sk- and you can only see it once
  5. Make sure your account has billing set up (Settings → Billing) — GPT-4o-mini is very low cost
1
Open your project's Environment Variables settings

Copy and paste this URL directly into your browser address bar:

https://vercel.com/wodjric-2732s-projects/pqe-ai-assistant/settings/environment-variables
You'll be asked to log in if your session has expired. Use the same account you deployed from.
2
Click "Add New" at the top of the page

Look for an Add New button near the top of the Environment Variables section. Click it — a form will expand below.

3
Fill in the Key and Value fields

Enter exactly the following — copy and paste the Key name to avoid typos:

Key (name)
OPENAI_API_KEY
Value
Paste your key here — it starts with sk-proj-... or sk-...
Important: Never share this key with anyone or paste it into any code file. Vercel stores it encrypted and only injects it into your server-side routes at build time.
4
Select which environments to apply it to

You'll see three checkboxes. Tick Production at minimum. Optionally also tick Preview and Development if you want AI to work in dev mode too.

Production ← required
Preview (optional)
Development (optional)
5
Click Save

Click the black Save button. The key will appear in the list with its value hidden (shown as ••••••••).

Save
6
Redeploy to apply the new environment variable

Environment variables only take effect after a new deployment. To redeploy:

1. Click Deployments in the top navigation of your project

2. Find the latest deployment at the top of the list

3. Click the ⋯ (three dots) button on the right side of that row

4. Click Redeploy

5. In the confirmation dialog that appears, click Redeploy again

The deployment takes about 60 seconds. A green "Ready" badge will appear when done.
7
Test the AI features

Once redeployed, open your app and test:

1. Create or open an audit → go to Audit Hub → click Generate Audit Prep Plan

2. If you see a suggestion appear in the amber box, AI is working correctly

3. If you see an error, double-check the key was saved correctly (no extra spaces)

✓ All AI features will then be active:
  • Audit preparation plan (Audit Hub)
  • End-of-day daily summary (Audit Hub)
  • Per-question verification guidance (Auditor Verification)
  • Finding suggestion (Findings form)
  • OCR document analysis — photo → GPT-4o vision
  • Technical drawing CTF analysis — photo → GPT-4o vision
  • Voice recording transcription — Whisper
