1. Overview and Purpose

PQE AI Assistant is a mobile-first web application designed to support Procurement Quality Engineers, Supplier Quality Engineers, and manufacturing process auditors throughout the complete supplier qualification and onsite audit lifecycle.

The application combines a structured audit workflow with AI assistance (powered by OpenAI GPT-4o and Whisper) to help auditors prepare more effectively, identify risks faster, and produce professional audit records — while keeping all final decisions firmly in human hands.

⚠ PROTOTYPE VERSION — All data is stored in your browser's IndexedDB only. Data is not encrypted at rest and will be lost if you clear your browser data. This application is not approved for storing real production supplier data, confidential drawings, or personally identifiable information until a server-side database is deployed.

Target Users

  • Lead Auditors / PQEs — plan, execute, and close supplier audits
  • Supplier Quality Engineers — verify corrective actions and manage CAR follow-up
  • Supplier Contacts — complete pre-audit self-assessments (via the Supplier Assessment page)
  • Quality Managers — review the Supplier Risk Dashboard and audit history

2. Getting Started

Accessing the App

  1. Open https://pqe-ai-assistant.vercel.app in any modern browser (Chrome, Safari, Firefox, Edge).
  2. The app works on mobile and desktop. On mobile, add it to your home screen for a native-app feel.
  3. No login or account is required for the prototype version.

First-time Setup

  1. Go to Settings (navigation bar) and enter your name in the Auditor Preferences field. Click Save.
  2. Your name will be auto-filled as Lead Auditor on new audits and as the verifying auditor on approvals.
  3. Go to Checklists and import your Excel audit questionnaire to create your first checklist template.
Tip: The app works offline once loaded. All audit data is stored locally in your browser — no internet connection is required for data entry, only for AI features.

4. Checklist Templates

Checklists are imported from Excel workbooks (.xlsx) and stored as controlled templates. The original workbook is preserved read-only in your browser storage.

Importing a Checklist

  1. Navigate to Checklists in the navigation bar.
  2. Click Import Excel Checklist.
  3. Select your .xlsx file. The file must be structured with columns for reference, question text, guidance, max score, and mandatory flag. (See Excel format below.)
  4. Enter a Checklist Name and Revision number.
  5. Click Import. The checklist is parsed and stored. The original file is preserved.

Expected Excel Format

Section title (merged row)—————
Reference (e.g. 4.1.2)Question textGuidance notesMax scoreScoring basisMandatory (Y/N)

Rows where Column A contains a section heading (no reference number format) are treated as section dividers.

5. Creating an Audit

  1. Go to Audits → click + New Audit.
  2. Select the Checklist Template to use for this audit.
  3. Fill in Supplier Name, Site / Location, and Supplier Contact.
  4. Select Audit Type: Qualification, Process, Line, Investigation, or CAR Verification.
  5. Set Audit Dates (one or more days).
  6. Enter the Lead Auditor name and any additional Team Members.
  7. Add a Scope description — this is used by AI features for context.
  8. Click Create Audit. You are taken to the Audit Hub.

7. Supplier Self-Assessment

The supplier (or the auditor on behalf of the supplier) fills in a conformance status, score, response text, and supporting evidence for each checklist question.

Steps

  1. From the Audit Hub, click Supplier Self-Assessment.
  2. Select the form language: English, Español, Deutsch, Français, or 中文 using the language toggle at the top.
  3. For each question, click to expand and select a Conformance Status: Conforming, Minor NC, Major NC, Not Applicable, or Not Assessed.
  4. Enter a score (if the checklist has scoring), a written response, and any comments.
  5. Attach supporting evidence files (photos, PDFs) using the Upload Evidence button.
  6. Click Save Response for each question. Progress is shown in the bar at the top.
Supplier responses are kept completely separate from auditor verdicts. A supplier marking a question "Conforming" does not auto-approve it. The auditor must independently verify each item.

8. Auditor Onsite Verification

This is the core onsite audit activity. The auditor reviews each checklist item independently of the supplier response and records their own verdict based on objective evidence.

Steps

  1. From the Audit Hub, click Auditor Verification.
  2. For each question, click to expand. The supplier's response is shown in a blue read-only panel for reference.
  3. Optionally click Get AI Verification Guidance for suggested follow-up questions and evidence to request. AI
  4. Select your Auditor Verdict: Conforms, Minor NC, Major NC, Not Verifiable, or Not Applicable.
  5. Enter a score (if scored checklist) and detailed Auditor Notes recording objective evidence observed.
  6. Attach photos and documents as evidence using the Evidence upload.
  7. Check the I confirm approval checkbox to mark the item as auditor-approved.
  8. Click Save Verification.
  9. When all items are assessed, click Proceed to Findings.
Critical control: The approval checkbox (isApproved) can only be set by explicitly checking the box. AI suggestions have absolutely no effect on this field. Unchecking reverts to unapproved regardless of AI content.

Verdicts Explained

VerdictMeaning
ConformsObjective evidence confirms the requirement is met
Minor NCPartial non-conformance — does not prevent use but requires correction
Major NCSignificant non-conformance — requires corrective action before approval
Not VerifiableInsufficient evidence available during the audit to verify
Not ApplicableThe requirement does not apply to this supplier / process

9. Findings Log

Findings are formal records of non-conformances, observations, and improvement opportunities identified during the audit.

Creating a Finding

  1. Go to Findings in the navigation (or via Audit Hub → Findings).
  2. Select the relevant audit from the dropdown.
  3. Click + New Finding.
  4. Select the Classification: Major NC, Minor NC, Observation, or OFI.
  5. Enter a Title and Description.
  6. Optionally click Get AI Finding Suggestion to get a draft finding statement. AI
  7. Check Raise a CAR if a corrective action is required — a CAR record is created automatically.
  8. Click Create Finding.

Approving a Finding

Findings are created as Draft. To make a finding official, expand it and click Approve Finding. This sets isAuditorApproved = true and records the approving auditor. AI cannot approve findings.

10. Corrective Action Requests (CARs)

CARs follow a full 8D problem-solving workflow from containment through to auditor-verified closure.

Managing a CAR

  1. Go to CARs and select the audit.
  2. Expand the CAR. Fill in Owner (supplier contact responsible) and Due Date.
  3. Fill in each 8D field: D1–D3 Containment, D4 Root Cause, D5–D6 Corrective Action, D7 Effectiveness.
  4. Upload effectiveness evidence files.
  5. Click Save Updates to save changes, or Advance to Next Step to move to the next 8D stage.
  6. When the CAR is at EFFECTIVENESS stage and you have verified the actions are effective, click ✓ Auditor Verified Closed. A confirmation dialog appears.
Critical control: isAuditorVerifiedClosed can only be set by the explicit confirmation dialog. AI cannot close CARs. Past-due CARs are automatically flagged OVERDUE and shown on the Dashboard.

12. Vertical Evidence Trace

The Evidence Trace page allows the auditor to verify traceability from a CTF (Critical-to-Function) characteristic on a drawing through to the inspection result — a complete vertical chain.

Trace Chain Steps

  1. Drawing — CTF characteristic with balloon number, tolerance, and datum
  2. PFMEA — Characteristic listed with failure mode, severity, occurrence, detection
  3. Control Plan — Method, frequency, reaction plan, responsible party
  4. Work Instruction — Operator instruction references the characteristic
  5. Measurement System — Calibrated equipment with GR&R ≤ 10%
  6. Inspection Result — Actual data showing conformance (Cpk ≥ 1.33 / 1.67 for CTF)

You can create multiple characteristics (chains) for the same audit. Each link can be Verified, Gap Found, Not Applicable, or Not Checked. Verifying a link requires confirmation. Evidence can be attached to each individual link in the chain.

13. Supplier Qualification Decision

The Qualification page records the formal APPROVE / CONDITIONAL / REJECT decision. It is accessible from the Audit Hub → Qualification.

Mandatory prerequisites before a decision can be recorded:
  • Audit report must be generated
  • Report must be auditor-approved
  • Recommended: no open major findings, no open CARs
AI cannot make, suggest, or influence the qualification decision.

Decision Options

DecisionMeaning
✓ ApprovedSupplier meets all requirements. Approved for production supply.
⚠ Conditionally ApprovedApproved subject to conditions being met and verified. Record conditions in the text field.
✕ RejectedSupplier does not meet requirements. Not approved for production supply.
◷ DeferredDecision deferred pending further information or re-audit.

Clicking any decision button opens a confirmation dialog showing the supplier name, decision, auditor name, and date before recording.

14. Audit Report

The Report page generates a print-ready HTML audit report and records the auditor's formal approval.

Generating the Report

  1. From the Audit Hub, click Generate Report.
  2. Select a Qualification Recommendation.
  3. Write the Conclusion — summarise findings and basis for recommendation.
  4. Optionally edit the Confidentiality Notice.
  5. Click 📄 Generate & Preview Report. The report opens in a new tab.
  6. In the new tab, use File → Print → Save as PDF to save the report.

Approving the Report

  1. After generating, click ✓ Approve Report (Auditor) on the report settings page.
  2. A confirmation dialog shows your name and asks you to confirm this represents your professional judgement.
  3. Click Proceed. The report is marked Auditor Approved with your name and timestamp.
  4. Once approved, the Qualification page prerequisites are met.

18. AI Features and Controls

What AI Can Do

  • Generate risk-based audit preparation plans
  • Suggest follow-up questions and evidence requests for checklist items
  • Draft finding statements based on auditor notes and verdict
  • Generate end-of-day audit summaries
  • Generate day-by-day agenda and opening meeting notes
  • Extract and analyse content from photographed documents (OCR)
  • Identify CTF characteristics from technical drawing photos
  • Transcribe recorded audio of audit conversations (Whisper)

What AI Cannot Do — Ever

Every AI-generated output is displayed in an amber box clearly labelled ✦ AI SUGGESTION — NOT AUDITOR APPROVED. An expandable disclaimer explains the AI's limitations. AI suggestions are never automatically written into any form field.

19. Settings, Backup and Reset

Auditor Preferences

Enter your name in Settings → Auditor Preferences. This auto-fills auditor fields on new audits and approvals.

Scoring Thresholds

Set pass/conditional/fail percentage thresholds in Settings → Scoring Thresholds. These are stored in localStorage and used as reference — the qualification decision still requires explicit auditor sign-off.

Exporting a Backup

  1. Go to Settings → Export Audit (JSON Backup).
  2. Select the audit from the dropdown.
  3. Click Export JSON. A .json file is downloaded to your device.
Photo and document blobs are NOT included in JSON exports (too large). Only structured data (checklist, responses, verifications, findings, CARs, report) is exported. Re-attach evidence files manually after importing on a new device.

Importing a Backup

  1. Go to Settings → Import Audit from Backup.
  2. Click Choose Backup File and select a previously exported .json file.
  3. If an audit with the same ID exists, it will be overwritten.

Factory Reset

Settings → Factory Reset permanently deletes ALL data in this browser: audits, checklists, findings, CARs, evidence, and reports. You must type RESET in the confirmation prompt to proceed. Export all audits before resetting.

22. Frequently Asked Questions

AI features show "not configured" — what do I do?

Add your OPENAI_API_KEY in the Vercel dashboard under Environment Variables and redeploy. See the setup guide for step-by-step instructions.

I cleared my browser data and lost all my audits.

IndexedDB data is cleared when you clear browser storage. Always export JSON backups regularly. If you had a backup, restore it via Settings → Import. Photo evidence cannot be recovered.

Can two people use the app at the same time?

Not in the prototype — each user has their own browser storage. Real-time collaboration requires a server-side database (future version).

The app shows a "Prototype" banner — is this normal?

Yes. The banner is a reminder that this is prototype storage only, not a production quality record system. It cannot be dismissed permanently in the current version.

Can I use the app on my phone without internet?

Yes — once the app has loaded, a Service Worker caches the app shell so it works offline. AI features (text suggestions, OCR, transcription) require an internet connection. All audit data entry works offline.

The Excel import failed — what format does the file need to be?

The importer reads the first worksheet. Section rows are detected by having no numeric reference in the first column. Each question row should have: reference, question text, guidance, max score (number or blank), scoring basis (text), mandatory flag (Y or blank). Use the existing checklist template as a reference.

How do I print the audit report to PDF?

From the Report page, click Generate & Preview Report. The report opens in a new tab. Use Ctrl+P (or Cmd+P on Mac) → change destination to Save as PDF → Save.

How do I print this manual to PDF?

Open https://pqe-ai-assistant.vercel.app/manual.html in your browser, then use Ctrl+P / Cmd+P → Save as PDF.
